- **Status:** open

- **Effort:** S

## DOM-015 — Names: normalisation, the Public Suffix List and reversed keys

- **Status:** open
- **Priority:** P1
- **Effort:** M
- **Source:** design A section 4.1 and design B section 4; `docs/architecture.md` section 3.1 and section 3.2. The operator ruling 2 of 2026-10-27 asks for queries on any suffix or parent domain. Reversed keys make each one a contiguous range.
- **Problem:** every adapter must turn a raw string into the same name, the same suffix and the same key. No shared function exists. A different normalisation in two adapters splits one name into two records.
- **Premise:**
  - MEASURED 2026-10-27 (design A M5, `docs/research/2026-10-27-design-a/scripts/thc-day.mjs`): THC's 2026-10-26 dump holds 38,474,309 lines. 9,503,378 (24.7%) are wildcards `*.x`. After lowercasing and stripping wildcards, 32,554,702 names remain. The average name is 33 bytes. The charset check refused 0 lines. 4 lines were themselves a public suffix.
  - MEASURED 2026-10-27 (design B M2, `docs/research/2026-10-27-design-b/scripts/thcstat.mjs`): 217,443 lines (0.57%) hold upper case. The order is a locale collation with 10.3 million adjacent inversions. So the file is not bytewise sorted, and the documented "sorted lowercase" is wrong.
  - MEASURED (design A M5): registrable domains 11.16 million with the ICANN section of the PSL, sites 14.16 million with the full list. Design B counted 11,162,434 and 14,142,438. The two PSL files differ in version, so no test asserts these numbers. DOM-009 re-measures them with the pinned file.
  - MEASURED (design A section 3.1): Zonestream sends names with a trailing dot (`creatorwide.com.`). cenk's lists carry Unicode names (design B section 13). Both need conversion and validation.
  - READ `https://publicsuffix.org/list/public_suffix_list.dat`: 338,012 B on 2026-10-27 (design A M4). It has an ICANN section and a private section (`github.io`, `workers.dev`, `pages.dev`). It has wildcard rules (`*.x`) and exception rules (`!x`).
  - MEASURED (design B M2): `np.com` held 6,764 names in THC's 2026-10-26 file. The key of the suffix `com.np` is `np.com`. `com.github` held 0, because a daily dump holds only the certificates issued that day.
  - Reference code: `docs/research/2026-10-27-design-a/scripts/psl.mjs` (48 lines), `docs/research/2026-10-27-design-b/scripts/psl.mjs` (29 lines), `.../revlabel.mjs`, `.../regdoms.mjs`.
- **Approach:**
  - **`packages/names/src/normalise.ts`.** `normalise(input)` returns `{ name, wild }` or `{ refused: REASON }`. Steps as `docs/architecture.md` section 3.1: lowercase ASCII; for a string with a byte above 0x7f call `domainToASCII` from `node:url` (an empty result is a refusal); strip one trailing dot; strip a leading `*.` and set `wild`; refuse a byte outside `[a-z0-9_.-]`, a label over 63 bytes, a name over 253, an empty label, a name with no dot, a name that is itself a public suffix. The ASCII path is a single byte loop. No regular expression runs per name.
  - **`packages/names/src/psl.ts`.** `loadPsl(text)` builds a trie keyed by reversed labels with the ICANN and private sections marked. `split(name, { privateSection })` returns `{ suffix, reg, site, labels }` with the PSL algorithm (longest match, wildcard, exception). `psl.sha256` is the hash of the file text.
  - **`packages/names/src/key.ts`.** `key(name)` reverses the labels (`api.example.com.np` to `np.com.example.api`). `fromKey(key)` inverts it. `rangeOfDescendants(key)` returns `[key + ".", key + "/")`. The parent itself is a point lookup. ⚠ A range that starts at the parent key itself also takes `np.com-x`, because `-` (0x2D) sorts before `.` (0x2E). `/` (0x2F) is not in the charset, so no key sorts inside the half-open range except descendants. Tests cover `np.com-x`, `np.com0` and `np.comz`.
  - **Fixtures.** `packages/names/test/fixtures/psl-2026-10-27.dat` is a copy of the PSL. `ref-refresh.yml` (created by DOM-019) pushes the live file to the `ref` package daily and keeps its hash in `sources.json`. A new hash triggers a recompute of `suffix`, `reg` and `site` at the next compaction. `scripts/ref/fetch-psl.mjs` downloads the file, checks that it has both section markers and more than 9,000 rules, and prints the sha256.
  - **Tests.** Uppercase, trailing dot, wildcard, IDN (a label with a non-ASCII letter, such as u with a diaeresis, becomes its `xn--` form), a Unicode name from a cenk-style list, a 64-byte label, a 254-byte name, `_dmarc.example.com`, a name equal to a suffix (`co.uk`, `github.io` under the ICANN rule only), `np.com`, `com.np`, `co.uk`, `x.github.io` (`reg` is `github.io` under the ICANN section, `site` is `x.github.io` with the private section). A property test checks `fromKey(key(n)) === n`, and checks that key order equals the order of `(labels reversed)` compared bytewise.
- **Decision:** descendants are a half-open range `[key + ".", key + "/")` and the parent is a point read, not one range from the parent key. The single range is shorter to write and wrong for labels that start with a hyphen.
- **Depends on:** DOM-009, DOM-013
- **Prove:** `node scripts/test.mjs packages/names` passes. A planted defect that uses the key plus the highest code point as the upper bound makes the `np.com-x` test fail.
  - `node scripts/ref/fetch-psl.mjs` prints `sha256 HEX rules N` with N above 9,000 and exits 0.
  - `node packages/names/bin/split.mjs api.example.com.np x.github.io` prints `suffix com.np reg example.com.np site example.com.np` and `suffix io reg github.io site x.github.io`. The `site` column applies the private section, the other two columns apply the ICANN section only. The exact output format is in the test.
- **Found 2026-10-28T14:27Z (DOM-009):** `docs/research/measure/DOM-009/local-2026-10-26.stat.json` counts 1,516 names of THC's 2026-10-26 dump whose top-level label is all digits, with 256 distinct such labels (lines 117 and 121). The run took place on the operator's Windows workstation at 2026-10-28T11:19Z. `scripts/measure/regdoms.mjs` lines 37 to 41 read such a name as an address literal, such as `192.0.2.1`, that a certificate carried. These names pass the charset of `docs/architecture.md` section 3.1. This entry decides whether `normalise()` refuses them, records the decision with a recommendation, and holds it with a test. If it refuses them, section 3.1 changes in the same commit.
  - The same run converts each IDN rule of the PSL to ASCII (`scripts/measure/psl.mjs` line 64). Without the conversion, a name under a multi-label IDN rule such as `公司.cn` matches only its parent rule `cn`, so its registrable domain is one label too short (`scripts/measure/fixtures/thc/psl-mini.dat` lines 21 and 22 hold both rules, and `scripts/measure/psl.test.mjs` lines 102 to 104 split `x.xn--55qx5d.cn` under the converted rule). A name under a rule whose parent is an IDN label too, such as `個人.香港`, falls back to the rule `*` and is one label too short in the same way. A single-label IDN rule gives the same split with or without the conversion, because the rule `*` is also one label. So `loadPsl` converts each rule that holds a byte above 0x7f with `domainToASCII`, and a test splits a name under such a rule. No script in the tree records how many names a day the conversion moves. DOM-009's closing run re-derives that count.

## DOM-016 — The source registry and the adapter contract

- **Status:** open
- **Priority:** P1
- **Effort:** M
- **Source:** design A section 5.5 and design B section 5.4; `docs/architecture.md` section 3.5 and section 5.6. The operator ruling 1 of 2026-10-27: a VPS ingester is one more source, if a core source shuts down.
- **Problem:** about twenty sources feed the data, each with its own cadence, precision, failure mode and bit in a source mask. Nothing fixes the shape of an adapter, assigns the bits, or holds `docs/sources.md` equal to the code. A source added later could reuse a bit, which corrupts every stored record.
- **Premise:**
  - READ `docs/architecture.md` section 3.5: `sources.json` has `id`, `bit` (0 to 63, never reused), `family`, `datasets`, `precision` (`second` or `day`), `kind`, `basis`, `cadence`, `band`, `urls`, `fetched`, `status` and `through`.
  - READ `docs/architecture.md` section 5.6: an adapter is a directory `adapters/ID/` with `source.json`, a module with `run(cursor, ctx)` that returns `{ segments, cursor, stats, errors }`, and fixtures with a test. An adapter never writes the root, `state` or another source's tag. A failed adapter fails alone.
  - The initial bit table: 0 `thc-ct`, 1 `oi-nrd`, 2 `oi-nrd-fqdn`, 3 `oi-nrd-confirmed`, 4 `oi-cs`, 5 `ct-le`, 6 `ct-geomys`, 7 `ct-ipng`, 8 `isc-new`, 9 `whoisds`, 10 `cenk-nrd`, 11 `hagezi-nrd`, 12 `oi-zone`, 13 `sk-nic`, 14 `oi-zonediff`, 15 `dotgov`, 16 `rdap`, 17 `ct-godaddy`, 18 `vps-ct` (reserved), 19 `oi-measure`, 20 `crtsh`, 21 `zone-walks`. CZDS has no bit (ruling 13). `thc-rdns` feeds only the reverse index and has no bit.
  - Families: `ct` for `thc-ct`, `oi-cs`, `ct-*`, `crtsh`, `oi-nrd`, `oi-nrd-fqdn`; `registry+ct` for `oi-nrd-confirmed`; `isc` for `isc-new`; `whoisds` for `whoisds` and `cenk-nrd`; `stamus` for `hagezi-nrd`; `registry` for `oi-zone`, `sk-nic`, `oi-zonediff`, `dotgov`, `rdap`; `nsec-walk` for `zone-walks`; `dns` for `thc-rdns` and `oi-measure`.
  - READ design B section 4: a source's precision belongs to its id. THC dumps are `day`. Kafka and tiles are `second`. ISC, WhoisDS and the lists are `day`. A source that changes precision gets a new id.
  - READ design A section 8.2: a segment is accepted only inside its expected volume band, relative to recent history. THC's volume fell to about a third in early October (984 and 957 MB on 10-01 and 10-02, 445 MB on 10-03, 77 to 340 MB a day from 10-05; MEASURED 2026-10-27T09:34:52Z), so a fixed band fails and a baseline that never moves fails too (architecture section 5.8).
  - `docs/sources.md` is the human table of sources. The registry and the table must agree.
- **Approach:**
  - **`packages/adapter/src/types.ts`.** `Source` (the `source.json` shape), `Segment` (`source`, `dataset`, `window`, `cursorBefore`, `cursorAfter`, `count`, `precision`, `bytes`, `sha256`, `raw` optional), `Cursor` (opaque JSON, at most 4 KiB), `RunResult`, `AdapterModule`, and `SegmentWriter` (an injected interface; DOM-017 and DOM-019 supply the real one, so this entry ships an in-memory writer for tests).
  - **`packages/adapter/src/validate.ts`.** `validateSource(json)` with a hand-written validator and exhaustive tests (no dependency). It checks every field of section 3.5, the id grammar `[a-z0-9]+(-[a-z0-9]+)*`, a `failure_modes` list with at least one string, `band` as `{ metric, min, max, relative }`, and that `bit` equals the entry of `config/source-bits.json`.
  - **`config/source-bits.json`.** The append-only map from id to bit for the 21 ids above. A test fails when an id is removed, when a bit changes, or when two ids share a bit.
  - **`scripts/sources/build.mjs`.** Reads `adapters/*/source.json`, validates each, and writes `config/sources.json` (the registry, sorted by bit). `--check` exits 1 when the committed file differs. DOM-019's `ref-refresh.yml` pushes the file to the `ref` package as `sources-SHA12`.
  - **`packages/adapter/src/harness.ts`.** `runAdapter(adapter, { fixtureDir, cursor, now })` runs `run()` with a fake `fetch` that replays recorded answers from `fixtureDir/*.http.json` (each file: request method and URL, status, headers, body in base64). A request with no recording fails the test. The harness checks that two runs with the same inputs return equal segments, and that `cursorAfter` of run 1 is a valid `cursorBefore` for run 2.
  - **`packages/adapter/src/band.ts`.** `checkBand(count, history, band)` returns `ok`, `quarantine` or `hold`. `history` is a list of `{day, count, quarantined}`. A relative band compares with the median of the last 7 days that were not quarantined: below 40% of it is `quarantine` for a day source and `hold` for others, and above 250% is `hold`. **Step change.** For a day source, 3 consecutive observed days below the floor reset the baseline to the median of those 3 days, and the third is `ok`; a day with no file neither counts nor breaks the run. The test replays the daily sizes of THC's bucket from 2026-09-01 to 2026-10-26 (a fixture of 54 numbers) and asserts: 10-05 and 10-06 `quarantine`, 10-07 `ok` with a baseline of 294 MB, 10-15 (77 MB) `quarantine`, and without the reset all 21 days from 10-05 on `quarantine`. DOM-018 calls it.
  - **Docs test.** `packages/adapter/test/docs.test.ts` reads the first cell of each table row of `docs/sources.md` that holds a backticked source id. It asserts that the set of ids equals the keys of `config/source-bits.json`, and that every `adapters/ID/source.json` has a row. If the table shape of that file differs, fix the parser, not the file.
- **Decision:** a hand-written validator and an append-only bit map, not JSON Schema with a library. The registry is 21 rows and one grammar. A library adds a dependency for no gain. The map is a file of its own so that deleting an adapter directory never frees a bit.
- **Depends on:** DOM-013, DOM-015
- **Prove:** `node scripts/test.mjs packages/adapter` passes. Planted defects: a `source.json` with a reused bit, a missing `failure_modes`, an adapter that calls an unrecorded URL, and an adapter whose two runs differ each fail their test.
  - `node scripts/sources/build.mjs --check` exits 0 on the committed `config/sources.json`.
  - `node scripts/test.mjs packages/adapter --name "docs"` passes: the ids of `docs/sources.md` and of `config/source-bits.json` are equal.
